# TechShare Docs

Docusaurus documentation site for the TechShare Order & Subscription Management workshop.

Covers API reference, architecture guides, and step-by-step tutorials for `techshare-be` (Spring Boot) and `techshare-fe` (React).

## Run locally

```bash
npm install && npm run dev
```

Open http://localhost:3000/docs/.

## Deploy

Pushes to `main` automatically deploy to GitHub Pages via `.github/workflows/deploy.yml`.

Live site: https://techshare-java.github.io/docs/
